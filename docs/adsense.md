# 애드센스 — 승인부터 운영까지

> **누가 읽나**: 사장님과 `orchard`. **에이전트에게 넘기지 않는다.**
> 블로그 저장소의 `docs/adsense.md` 와 같은 내용이다. **이 파일이 원본이다.**
> 고칠 때는 여기를 고치고 그쪽에 복사한다.

**승인 신청은 글 15~25편이 쌓인 뒤에 한다.**

---

## 심사관이 묻는 것은 하나다

> **"여기에 내 광고주의 광고를 붙여도 광고주가 화내지 않을까?"**

**애드센스 심사는 글솜씨 대회가 아니라 신뢰도 검사다.** 거절 패턴은 넷뿐이다.

| # | 거절 사유 | 심사관이 읽는 신호 |
|---|---|---|
| 1 | **콘텐츠 부족** — 개수가 적거나, 많아도 한 편이 얇다 | "진지하게 운영하지 않는다" |
| 2 | **복제·저품질** — 베끼기, 기사 옮기기, 짜깁기 | "정직하지 않다" |
| 3 | **정책 위반** — 단정적 투자 권유, 출처 없는 정보 | "광고 옆에 두면 위험하다" |
| 4 | **탐색 곤란** — 메뉴 없음, 빈 페이지, 신뢰 페이지 부재 | "아직 준비가 안 됐다" |

**거절은 「빠뜨린 항목의 신호」로 읽는다.** 그래야 고칠 행동이 남는다.

## 1. 신청 전에 갖출 것

### 이미 된 것

| 항목 | 어디에 |
|---|---|
| 신뢰 페이지 3장 | 블로그 `/about/` `/privacy/` `/contact/` — 메뉴에서 한 번에 보인다 |
| 쿠키 고지 문구 | 블로그 `content/privacy.md` |
| 실제 받을 수 있는 이메일 | `contact@onioniworks.com` |
| 면책 문구 자동 삽입 | 블로그 `layouts/_partials/extend_post_content.html` — 개별 글로 못 끈다 |
| 게시자 ID를 설정값으로 | 블로그 `hugo.toml` 의 `adsenseClient`. 하드코딩 없음 |
| 광고 코드 한곳에 | 블로그 `extend_head.html` 하나 |
| 검수 게이트 | `draft: true` 가 기본. 사람이 손으로 `false` 로 바꿔야 발행된다 |
| 빈 카테고리 차단 | 글 0편 카테고리는 목록·검색에서 빠진다 |

### 신청 전에 채워야 할 것

| # | 항목 |
|---|---|
| 1 | **글 15~25편** |
| 2 | **소개 페이지의 운영자 문단** — "누가, 왜 운영하는가"를 증명하는 자리다 |
| 3 | **파비콘** |
| 4 | **사이트 제목·설명 확정** (`hugo.toml`) |

### 승인 전에는 제휴 링크 글을 쓰지 않는다

| 승인 전 | 승인 후 |
|---|---|
| 제도·개념·비교·계산 — **정보성만** | 제휴 링크 허용 (`affiliate: true`) |

**재테크 갈래가 특히 그렇다.** 승인이 날 때까지는 그쪽 글을 정보성으로만 쓴다.

## 2. 신청 30일 전부터 — 순서대로

| 기간 | 할 일 |
|---|---|
| 1~7일 | 콘텐츠 점검 — 얇은 글 보강, 복제 의심 글 재작성 |
| 8~12일 | 신뢰 페이지 마무리 (운영자 문단·파비콘) + 메뉴 동작 확인 |
| 13~15일 | 단정 표현 제거 — "무조건", "보장", "확실히" 전수 검색 |
| 16~22일 | 탐색 점검 — 깨진 링크, 2~3클릭 내 도달, **휴대폰으로 직접** 메뉴 확인 |
| 23~28일 | 자가 점검 (아래). **✗ 하나라도 있으면 신청을 미룬다** |
| 29~30일 | 신청. **심사 중에도 글은 계속 발행한다** |

### 자가 점검 — ✗가 하나라도 있으면 미룬다

- [ ] 글이 15편 이상이고, 각 글이 검색자의 질문에 실제로 답하는가
- [ ] 남의 글을 옮기거나 짜깁기한 글이 없는가
- [ ] 단정적 권유·보장 표현이 없는가 (`guides/writing-rules.md` 법·신뢰 절 기준)
- [ ] 소개·개인정보처리방침·연락처가 메뉴에서 한 번에 보이는가
- [ ] **소개 페이지에 누가 운영하는지 적혀 있는가**
- [ ] 빈 카테고리·"준비 중" 페이지가 없는가
- [ ] 깨진 이미지·링크가 없는가 (전수 클릭)
- [ ] 연락처 이메일로 실제로 메일이 오는가 (직접 보내 본다)
- [ ] **휴대폰으로 열어** 메뉴가 동작하는가
- [ ] 파비콘이 있는가

**거절은 큰 결함보다 자잘한 미완성의 누적에서 더 자주 온다.**

## 3. 승인 뒤 — ads.txt

승인되면 게시자 ID(`ca-pub-…`)를 받는다. **두 곳에 넣는다.**

**① `hugo.toml`**

```toml
adsenseClient = 'ca-pub-XXXXXXXXXXXXXXXX'
```

**② `static/ads.txt`** — **이때 만든다. 미리 만들면 틀린 ID가 박힌다.**

```
google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
```

- `pub-` 뒤 번호는 **본인 것**이어야 한다. 마지막 칸은 구글 인증 ID로 누구나 같다
- **`ca-pub-` 이 아니라 `pub-` 으로 시작한다.** `hugo.toml` 과 접두사가 다르다
- 없으면 "승인된 광고 판매자 없음" 경고가 뜨고 수익이 제한된다
- **구글 재크롤링에 며칠 걸린다.** `https://blog.onioniworks.com/ads.txt` 가 열리는지만 확인하고 기다린다

## 4. 광고 배치 — 승인 뒤에 정한다

**광고는 콘텐츠의 손님이지 주인이 아니다. 한 번 제대로 세팅하고 가끔 점검한다.**
**배치에 매달리는 시간에 글 한 편을 더 쓴다.**

**광고를 늘리면 단가가 내려간다.** 좋은 자리는 희소할 때 비싸다.
두 배로 늘려도 단가가 절반이면 수익은 제자리다.

### 어디에 두나 — 시선이 쉬는 곳

- 본문 첫 문단 근처
- 문단과 문단 사이
- 본문 끝

**판정은 하나다 — "내가 독자라면 어디서 잠깐 멈추겠는가."**

### 자동광고 + 수동 1~2곳

| | 자동광고 | 수동배치 |
|---|---|---|
| 장점 | 새 글에도 자동으로 붙는다 | 정밀한 통제 |
| 단점 | 과밀 위험 | 손이 많이 간다 |

**자동광고로 전체를 깔되 핵심 자리 한두 곳만 수동으로 둔다.**
**병용할 때는 자동광고 밀도를 한 단계 낮춘다.**

### 모바일을 먼저 본다

- 첫 화면(스크롤 전)을 광고가 점령하지 않았나
- 본문과 광고 사이 여백이 있나
- 앵커 광고의 **닫기(X) 버튼이 분명히 보이나**
- 전면 광고는 **페이지 전환 시에만.** 읽는 도중 덮지 않는다

### 절대 하지 않는 배치 넷

1. **콘텐츠 위장** — 광고를 본문 글씨·색과 똑같이
2. **클릭 강요 위치** — 메뉴·버튼 옆
3. **콘텐츠 없는 페이지의 광고** — 오류·빈 페이지
4. **화면 덮기** — 특히 닫기 버튼이 안 보이는 전면 광고

**넷의 공통점은 「방문자를 속이거나 가둔다」는 것이다.** 새 형식이 나와도 그것만 물으면 판단된다.

### 밀도는 숫자로 검증한다

**광고를 늘렸을 때 RPM(1,000회 노출당 수익)이 같이 오르면 유지, 떨어지면 과밀 신호다.**
**며칠이 아니라 몇 주 단위 추세로 본다.**

## 5. 계정을 날리지 않는 수칙

**절대 하지 않는 것**: 내 광고 클릭 · 지인에게 부탁 · 트래픽 구매.
**구글은 즉시 경고하지 않고 데이터를 모은 뒤 한꺼번에 조치한다.**

**월 1회 정책 센터를 확인한다.** 정지는 대개 경고라는 노란불이 먼저 켜진다.

> **승인의 보상은 천천히 쌓이지만, 정지의 손실은 한순간에 전부다.**
> 계정은 보통 1인 1개이고, 이의 신청이 거부되면 새 계정 우회도 막힌다.

## 6. 우리 도구가 대신 막아 주는 것

| 위험 | 우리가 막는 방법 |
|---|---|
| 검수 없이 발행 | 검수 세 걸음을 통과해야 `scripts/publish.py` 가 옮긴다 |
| 면책 문구 누락 | 템플릿이 자동으로 붙인다. 개별 글로 못 끈다 |
| 단정적 투자 권유 | `guides/writing-rules.md` 법·신뢰 + `scripts/gate.py` 의 법 넷이 반려한다 |
| 출처 없는 수치 | 작성 에이전트가 `research.md` 밖의 수치를 못 쓴다 |
| 같은 글 복제 | `scripts/kickoff.py` 가 슬러그 중복을, 착수가 14일 안 글감 중복을 잡는다 |
| 빈 카테고리 | 글 0편이면 목록·검색에서 자동으로 빠진다 |
| 광고 코드 흩어짐 | `extend_head.html` 한곳. GA 이중 삽입은 빌드가 실패한다 |
| 이미지 저작권 | **라이선스가 확인된 것만 받는다** — 스톡 세 곳과 공공누리 |
